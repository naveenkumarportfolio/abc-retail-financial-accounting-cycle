# ABC Retail Store – Complete Financial Accounting Cycle

An Excel-based practical accounting project where I worked through the complete accounting cycle of a retail business, from recording transactions to preparing financial statements.

## Project Overview

I created this project to improve my practical understanding of financial accounting and learn how different accounting records connect with each other.

The workbook covers the first month of operations of ABC Retail Store and uses Excel formulas to connect the journal, ledger and financial statements.

## What I Worked On

- Recorded business transactions using the double-entry accounting system.
- Prepared the General Journal.
- Posted transactions to the Ledger and T-Accounts.
- Prepared the Trial Balance.
- Created the Income Statement.
- Prepared the Classified Balance Sheet.
- Used Excel formulas to link accounting schedules.
- Added balance checks to review the accuracy of the records.

## Important Assumptions

This project is based on an educational case and does not represent the actual financial records of a real company.

- Original case amounts were converted using an illustrative fixed exchange rate of ₹88 per USD.
- All transactions are recorded within Month 1 because exact dates were not provided.
- The customer advance is treated as Unearned Revenue.
- Owner's Drawings are treated separately from operating expenses.
- The cost of goods sold for the credit sale is not recorded because the inventory cost was not provided.
- GST, depreciation, adjusting entries and closing entries are outside the project scope.
